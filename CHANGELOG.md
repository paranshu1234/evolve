# Changelog

## 0.1.0 — 2026-09-18

First native Windows desktop prototype: DirectX 12 helix viewport, orbit/pan/zoom, lighting, sequence selection and substitutions, immutable baseline comparison, undo/redo, local FASTA import and project save/open, mock composition analysis and CSV export. Includes portable core tests, Windows build automation and a WARP renderer smoke test.

Scientific models, biological dynamics, voice recognition and Unreal integration are deferred. The pre-existing project vision and console skeleton are retained.
