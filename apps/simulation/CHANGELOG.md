# Changelog

## Unreleased — experimental voice integration

- Shared typed workspace actions for buttons and guarded voice/text proposals.
- Separate native Voice Agent panel with transcript, typed fallback, explicit microphone enable, push-to-talk, Stop, local speech output and trusted one-use action confirmations.
- Optional, disabled-by-default OpenAI text conversation adapter with bounded context, allowlisted actions and no automatic sequence/file transmission.
- Portable parser/session/provider fixtures and an extended Windows WARP smoke path with microphone/cloud disabled.
- Live speech, provider and manual Windows verification remain release gates. See the voice documentation; no successful live test is implied.

## 0.1.0 — 2026-09-18

First native Windows desktop prototype: DirectX 12 helix viewport, orbit/pan/zoom, lighting, sequence selection and substitutions, immutable baseline comparison, undo/redo, local FASTA import and project save/open, mock composition analysis and CSV export. Includes portable core tests, Windows build automation and a WARP renderer smoke test.

Scientific models, biological dynamics, voice recognition and Unreal integration are deferred. The pre-existing project vision and console skeleton are retained.
