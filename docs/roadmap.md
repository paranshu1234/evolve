# Roadmap

## Current foundation

- Define the concept and research boundaries.
- Maintain the local C++ DNA visualization and virtual editing prototype.
- Establish independent website and desktop builds in one repository.

## Next steps

- Launch and refine the public showcase website.
- Publish selected research editions after review.
- Improve desktop application boundaries without changing its data guarantees.
- Evaluate one scientifically supported analysis adapter and its validation requirements.

## Longer-term exploration

An asynchronous scientific host, richer provenance, scalable geometry, and a possible browser workspace. These are directions for investigation, not implemented features or delivery commitments.
