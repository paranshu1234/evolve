# Research scope

Evolve is at a foundational stage. Its public [vision](../concept/vision.md) describes ambitions around restoration, correction, and voluntary enhancement for consenting adults. Scientific feasibility and safe implementation remain open questions.

The current prototype demonstrates schematic DNA visualization, substitutions, and sequence-composition statistics. It contains no DNA-to-phenotype model, treatment pathway, or biological-effect prediction.

Research priorities:

1. Define a bounded scientific question and the evidence needed to evaluate it.
2. Evaluate a supported model or solver with explicit inputs, units, reference identifiers, and limitations.
3. Record provenance and distinguish measured evidence, model output, and assumptions.
4. Validate results independently before making biological claims.

Working papers, collected references, and editable white-paper drafts remain in Drive. No white-paper edition is published by this migration. Approved editions can later be published with version, date, and a stable public link.
